# 后背固件 / Camera-back firmware

截至 2026-11-10，本项目收到并整理的资料中**没有可识别的 Aptus / Valeo 后背固件镜像、刷机包或后背固件解包结果**。

`../analysis/wiview-*/extracted/` 内的 ARM PE 可执行程序与 DLL 来自 HP iPAQ / Windows CE 的 WiView 客户端安装包。它们是 PDA 端软件，不能据此称作数字后背固件，也不能用于给后背刷机。

该目录保留给未来用户提供、来源和版本可核验的后背固件。届时应记录原始文件名、具体后背型号、固件版本、来源、大小、SHA-256，以及解包工具和方法。本次整理没有下载、生成、运行或刷写后背固件。

As of 2026-11-10, the supplied project material contains **no identified Aptus / Valeo camera-back firmware image, firmware updater, or extracted back-firmware payload**.

The ARM PE executables and DLLs in `../analysis/wiview-*/extracted/` were extracted from the HP iPAQ / Windows CE WiView client installers. They are PDA client software, not camera-back firmware, and must not be used as firmware images.

This directory is reserved for future firmware supplied with a verifiable origin and version. Record its original filename, exact back model, firmware version, source, byte size, SHA-256, and extraction procedure. No back firmware was downloaded, generated, executed, or flashed during this reorganization.
