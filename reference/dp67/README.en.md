# Leaf DP-67 1.2.1 static research material

[中文](README.md)

This directory retains the identifiable vendor installer from the user-supplied `Leaf DP-67 app.zip`, its embedded CAB, all 7 CAB members, and reproducible static analysis. The package directory identifies V1.2.1; the main client, `LEAFDP~2.001`, has file version **1, 2, 1, 2**. Analysis date: 2026-11-14.

The supplied ZIP also contains 4 PDA backups. The complete ZIP, PBF files, Mac metadata and temporary files are excluded. Only the first 12 bytes of the backup magic (`POCKETPCIMAG`) were read for classification; backup contents, device settings and credentials were not decoded. Provenance records names and SHA-256 hashes without inventing a public download URL. No vendor EXE or DLL was executed or loaded.

| Path | Contents |
| --- | --- |
| `original/LeafDP67-1.2.1-Setup.exe` | Original ARM Windows CE installer, 1,314,304 bytes |
| `original/LeafDP67-1.2.1.CAB` | Exact embedded resource `BIN/103`, 1,288,384 bytes |
| `extracted/` | All 7 CAB members, retaining historical manufacturer filenames |
| `analysis/binary-analysis.json` | Member sizes/hashes, PE metadata, imports/exports and data for SDK section comparisons |
| `analysis/connection-and-setting-evidence.json` | Setting writes, modified slots, Prefix, Framing, Ack, connection findings and limits |
| `analysis/disassembly/` | 15 bounded ARM function disassemblies, with virtual addresses and file offsets |
| `provenance.json` | ZIP, installer and CAB provenance/hashes and excluded data |
| `inventory.json` | Per-file size and SHA-256, excluding itself and Python caches |
| `analyze_dp67.py` | Static acquisition, analysis and read-only verification |

See the [DP-67 analysis report](../../docs/dp67-analysis.en.md). Its 12 core fields, optional Prefix and `.1` modified-slot behavior provide evidence for a Valeo compatibility experiment. No physical-back setting write or Bluetooth capture has established these differences as the cause of a disconnect.

After installing `requirements-research.txt`, run from the project root on Windows:

```powershell
.venv\Scripts\python.exe reference\dp67\analyze_dp67.py --zip "C:\Users\Legion\Downloads\Leaf DP-67 app.zip"
.venv\Scripts\python.exe reference\dp67\analyze_dp67.py --verify
```

The second command needs no user ZIP. It verifies the entire inventory, re-extracts the CAB and regenerates analysis from the retained installer in a system temporary directory, and compares every generated byte with the saved evidence. It does not modify this directory. Add `--zip <original ZIP>` to also verify the supplied archive. CAB extraction invokes only the system `expand.exe` utility, never the installer.
