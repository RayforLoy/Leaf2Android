# 功能缺口对照：0.2.0 基线 → 0.3.1

[English](feature-gap-matrix.en.md) · [项目首页](../README.md) · [功能与设备记录](implementation-status.md) · [使用说明](quick-start.md) · [0.3.1 说明](releases/v0.3.1.md)

更新：2026-11-14。**0.3.1（versionCode 4）实验性预发布。** 本表对照 0.2.0 基线与当前应用，区分标准路径、实验室和真实效果；0.3.1 的 Valeo 设置超时候选修正尚待实机复测。

已收到 **Valeo 22Wi、Aptus 22 蓝牙连接与读取照片成功**的基础报告；2026-11-14 另有 Valeo 修改设置超时报告，见 [设备与问题记录](implementation-status.md)。完整固件、手机 / 系统、应用版本和日志仍待补充。下列标准功能、实验室候选与用户假设分层记录；新增功能的硬件效果均待验证。用户已纠正 Aptus II 本身无蓝牙，不作为当前无线目标；原始 Aptus II 5 计划仅作历史记录。5.041 的 PDAInterface 是共享代码，不是该系列蓝牙硬件证据，不能由本表推定全系列已验收。

## 如何阅读状态

- **已有：** 0.2.0 已有代码；保留或扩展，不代表每项已经实机验证。
- **新增标准功能：** 0.3.1 已按明确协议接入仓库与界面，使用当前值、允许项及适用的回读；硬件效果待验证。
- **请求级：** 已发送有证据的请求并匹配 Ack，尚无已验证的当前状态读取；界面不宣称已切换成功。
- **实验室候选：** 提供模板或原始控制头主动验证，分别标客户端实证、固件入口或字段；未知值手填，回复只作观察，不报告语义成功。
- **用户假设：** 尚无已证厂商无线语法，用户可明确建立 USER HYPOTHESIS 探测；不把通用候选头写成提取到的接口。
- **部分 / 研究占位：** 标准功能只实现明确范围；没有有据模板或已知 tag 时保留研究说明，不自动生成厂商命令，仍可由用户在原始控制台输入单头。
- **未实现 / 硬件限制：** 尚无可用协议依据，或当前机械快门没有执行器。

## 经典 Aptus / Aptus 22 的独立复核

本轮主证据重新采用经典 **FirmwareAptus.UPD 4.701**，4,235,648 字节，SHA-256 `a2287716927a18c9bbd7834be327f592289f8a48aa2859b4d252b813cc82741a`。镜像含 Aptus 22 模型与 ISO 调整类，是共享镜像而非 Aptus 22 专用可刷包；配套 CE 1.8.6 的 27 个载入记录校验通过。不推定它已安装在用户后背上。

经典与共享 5.041 的 PDAInterface 都注册 9 类业务命令，与两版 WiView 实际构造对应。目录存在静态机型 / 模式条件，不证明所有设备支持全部命令，也没有由此发现独立 GetFile / LiveView tag。经典完整 ShootSetup、独立 Marking、图像扩展和 Gain 回复链均另追踪原字节，未套用 5.041 地址。见 [双语固件调查](firmware-bluetooth-survey.md) 与 [经典独立证据](../reference/firmware/analysis/controls-aptus-classic/evidence.json)。

完整配置不齐、值未下发、方言无法识别、状态在编辑期间改变、字符不能安全序列化或回读不一致时，不报告确认成功。单独看到 ISO 变化或收到 Ack 不能代替完整比较。底栏“后背 / Back”页提供配置与会话入口。

DP-67 路径来自用户安装包的 [静态对照](dp67-analysis.md)：短字段集、clone、contains(".1") 与包装器已有二进制证据；不据此认定真实 Valeo 超时根因。应用不修改 CEVersion，也不照搬原 12 秒×最多 3 次尝试／失败重同步策略，继续超时断流且不自动重试写入。

2026-11-14 用户只说明读图正常、改设置超时，未提供具体字段；截图只能证明 App 超时后关闭。网络没有找到 WiView 1.0.3 同机 A/B 或写 ISO 立即断线的直接证实，见 [独立研究](valeo-connection-research.md)。整事务锁与兼容模式的真实效果都待复测。

## 照片信息、标记与备注

| 功能 | 0.2.0 基线 | 0.3.1 与剩余边界 |
| --- | --- | --- |
| 照片属性与当前照片备注 | 已有读取和写备注 | 保留 GetPictureParams 与明确的后背备注操作，错误或无法解释的回复不报成功；真实固件效果仍需核对 |
| 本机星标 / 本机备注 | 已有 | 保持独立、持久保存在手机；不伪装为后背标记或默认拍摄备注 |
| XMP 解码与保留 | 缺失 | **新增：** 从已证实的 xmp_tag 头属性严格解码 Base64 / UTF-8；无属性不生成空 XMP，未经证实的二进制附件不猜作 XMP；拒绝损坏、不安全和歧义结构 |
| 后背 Good / Unmarked | 缺失，只有本机星标 | **新增：** 读取原有 XMP，定向改变 Leaf Flags 第三个字符并保留其余字符、命名空间及字段；写后回读 marking |
| 不带 XMP 的后背标记 | 客户端构造要求 XMP | **新增标准功能：** 经典 4.701 与共享 5.041 均证实独立 Marking；Sync 有 shootsetup / camerasettings 时允许 Marking-only。有 XMP 仍保留更新；无已识别方言且缺 XMP 则标准路径拒写，实验室可手动探测 |
| XMP-only / annotation+XMP 整包写入 | 缺失 | **新增实验室模板：** 使用原客户端构造并检查所提供 Base64 / XML；用户完整提供元数据包。标准功能保留定向 Flags 编辑，不宣称已有任意字段编辑器或已验证整包效果 |
| 照片来源校验 | 旧缓存不含新来源约束 | **新增标准约束：** 标记、备注、灰平衡、删除和内部 copy / move 要求本连接从当前后背读取的预览；重连 / 升级 / 进程重启后须刷新。实验室按手填目标执行，可绕过此类标准检查 |

标记改变的是 Flags 第三个**字符**，不是把服务器内部 bit 编号当成 XMP 下标。无关 XML 的语义字段保留，不承诺重新序列化后的 XMP 字节逐字节不变。预览缓存则原样保存收到的 JPEG 字节，二者不要混淆。

标准照片写入使用不持久化的连接 generation，不只比较地址或文件名；重连同一后背也须先刷新预览。实验室原始 / 整包写入的请求、目标与结果另外记录，不保证继承这项来源校验或标准回读判定。

| FactorySettings | 缺失 | **新增实验室模板：** 明确输入方向、颜色及可选现有配置名；不同于普通配置选择，重置 / 校准范围和恢复效果仍待验证 |

## 实验台的执行与记录边界

从“后背 / Back”页顶部进入实验室。16 个 WiView 模板和固件条目各自显示来源、未解项及影响；输入未知值不默认，单原始控制头最多 60 KiB，无出站二进制附件，手机超时 1–300 秒。用户检查目标与请求后确认；不自动遍历候选、fuzz 或刷固件。

可设回应标签、精确 file_name 和附件匹配。`*` 是首个完整帧观察，可能收到异步通知，不证明请求因果；空标签只发送。Error、非零 Ack、超时、取消和收到帧分别记录，不按普通成功处理。实验期间暂停普通拍后图像 / 配置刷新，发过实验后退出或取消会断开，不能保证撤销设备已收到的写入。

附件手机上限 16 / 64 MiB，断开修改、重连生效；原始 `.bin` 保存长度、SHA-256、前 256 B hex。最多 30 条记录、256 MiB 附件缓存预算。ZIP 包含完整脱敏请求 / 响应头、非敏感 header hex、原始附件、transport 日志、未匹配帧。PIN / 备注 / 版权 / XMP 等已知头字段默认 mask，发送字节不变；原始二进制不自动脱敏。详见 [实验室指南](quick-start.md#实验室手动验证)。

## 扩展目标与内部兼容字段

| 项目 | 当前结果 | 尚缺的依据 |
| --- | --- | --- |
| 完整 MOS 原片下载 | **标准未实现；实验室用户假设** | 未发现已证 GetFile 语法；可手动建立 USER HYPOTHESIS 空头并默认 `*` 观察，不能称固件提取接口。copy / move 或 `.mos` 路径不证明原片传输 |
| 连续 Live View | **标准未实现；实验室用户假设** | 无已确认连续传感器协议；可手动建立 USER HYPOTHESIS 候选头，默认首帧观察。重复 JPEG、FP 或拍后自动刷新不等于实时取景 |
| 当前技术相机遥控机械快门 | **硬件不支持** | 当前组合没有应用可驱动的释放执行器；保持手动释放 |
| 由手机刷写后背固件 | **未提供** | 固件归档、重建与分析不等于安全升级协议；本轮只是参考资料同步 |

`CEVersion` 是原 PDA 的**内部兼容字段**，不是缺失的摄影功能。实验室提供两版实证常量：1.0.2 为 `0x01060600` / `17171968`，1.0.3 为 `0x01080000` / `17301504`，仅手动兼容性实验，不自动用于握手，也不当作安卓或后背固件版本。
