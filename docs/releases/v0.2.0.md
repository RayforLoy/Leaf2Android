## 中文

本版统一使用 **Leaf2Android** 项目名称，提供中文和英文界面。默认跟随系统语言，也可在设置中独立选择简体中文或 English。应用中的产品系列名称改为 **Aptus / Valeo**。

- 保留现代和经典 PDA 两种风格；语言切换、风格切换和窗口尺寸变化时共用会话、当前照片、星标、备注和缩放状态。
- 完成 191 组中英文资源配对，包括连接状态、权限、诊断和协议错误说明。
- WiView 1.0.2 / 1.0.3 原始安装介质、解包文件、指南、静态分析和来源校验值统一放入 `reference/`。未发现可确认为后背本体固件的镜像；Windows CE 客户端 EXE/DLL 不标作后背固件。
- 提供详细中英文 README、安装、架构、协议、版本分析和功能验收说明。
- APK 使用独立发布密钥签名，启用代码和资源压缩；发布密钥保存在仓库外，不随源码或资源包提供。

**本次验证：** 25 项 Python 研究测试、24 项 Kotlin 协议测试及 6 项 Android API 36 模拟器测试全部通过。Debug 和 Release lint 均无错误；签名 APK 已通过签名、非调试构建及 16 KB ZIP / 原生库对齐检查。9 组模拟器截图覆盖中英文、窄屏、宽屏和横屏。测试样本为合成协议回复和生成的 JPEG，不能替代后背测试。

**使用边界：** 这是实验性预发布。Galaxy Z Fold7 / Android 16 / One UI 8.5 与真实 Aptus II 5 的蓝牙会话、连拍和后背操作仍待实机验收；Aptus / Valeo 名称不代表所有型号已兼容。完整 MOS 传输和连续实时取景尚未实现。当前技术相机机械快门仍须手动释放。

## English

This release standardizes the **Leaf2Android** name and adds Chinese and English interfaces. Language follows the system by default, with Simplified Chinese and English overrides in settings. The app's product-family label is now **Aptus / Valeo**.

- Modern and classic PDA styles share the session, selected photo, stars, notes and zoom state across language, style and window-size changes.
- 191 paired language resources cover the interface, permissions, connection state, diagnostics and protocol errors.
- Original WiView 1.0.2 / 1.0.3 media, extracted client components, guides, static analyses and pinned provenance are organized in `reference/`. No confirmed camera-back firmware image was supplied; Windows CE EXE/DLL files are identified as client software.
- Detailed bilingual README, installation, architecture, protocol, version-analysis and capability documents are included.
- The code- and resource-shrunk APK uses a separate release signing key. Private signing material remains outside the repository and all release archives.

**Validation:** all 25 Python research tests, 24 Kotlin protocol tests and 6 Android API 36 emulator tests passed. Debug and Release lint have no errors. The APK passed signature, non-debuggable release and 16 KB ZIP / native-library alignment checks. Nine emulator captures cover both languages and narrow, wide and landscape windows. Protocol replies and JPEGs used in tests are synthetic, not real-back captures.

**Limits:** this is an experimental pre-release. Real Bluetooth sessions, capture sequences and back-side operations with the Galaxy Z Fold7 / Android 16 / One UI 8.5 and Aptus II 5 remain unverified. The Aptus / Valeo family label does not establish compatibility with every model. Complete MOS transfer and continuous live view are not implemented. The current technical camera's mechanical shutter must be released manually.

The APK requires Android 12 or later. The source archive includes documentation, tools and reference material without caches or private keys. A separate reference archive and `SHA256SUMS.txt` are supplied. See the [English installation guide](https://github.com/RayforLoy/Leaf2Android/blob/main/docs/quick-start.en.md) and [verification record](https://github.com/RayforLoy/Leaf2Android/blob/main/research/reports/verification-status.json).
